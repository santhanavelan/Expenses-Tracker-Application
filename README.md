# Expense Tracker Application

A Java-based desktop application developed using Java Swing to manage daily income and expenses.

## Features
- Add, update, and delete transactions.
- Track income and expenses.
- Set category-wise budgets.
- Receive budget alerts.
- Search transactions.
- Generate monthly reports.
- Export transactions to CSV.
- Save data using text files.

## Technologies Used
- Java
- Java Swing
- File Handling
- Java I/O

## How to Run

1. Compile the program:
   `javac ExpenseTracker.java`

2. Run the application:
   `java ExpenseTracker`

## Objective

To help users manage their finances, track spending, monitor budgets, and maintain transaction records efficiently.
